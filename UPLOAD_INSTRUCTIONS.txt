NightRivet Moto V2

UPLOAD THESE FIVE FILES TO THE ROOT OF YOUR GITHUB REPOSITORY:
- index.html
- manifest.webmanifest
- sw.js
- icon-192.png
- icon-512.png

On GitHub:
1. Open the NIGHTRIVET-MOTO repository.
2. Tap Add file > Upload files.
3. Upload all five files.
4. If GitHub asks about index.html already existing, replace/overwrite it.
5. Commit the changes.
6. Wait a few minutes for GitHub Pages to update.
7. Remove the old home-screen shortcut/app.
8. Open the live site in Chrome and install it again.

The new installation should use the custom NightRivet icon.
